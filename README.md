# Talap — тренажёр ЕНТ по подписке

Онлайн-платформа для подготовки к ЕНТ: задания с разбором, пробное ЕНТ в формате 2026 года (120 заданий, 140 баллов, 4 часа), работа над ошибками, напоминания в Telegram. Оплата подписки переводом Kaspi, без автосписаний и процентов.

**Предметы в первой версии:** история Казахстана, математическая грамотность, грамотность чтения, математика, физика. Язык — русский.

**Деньги:** 2 990 ₸ за месяц или 7 490 ₸ за 3 месяца (цены меняются в админке). Первые 3 дня после регистрации — полный доступ, потом бесплатный режим: 20 заданий в день, одно пробное ЕНТ и по одному тесту по предмету.

## Что сделать перед запуском

1. **Telegram-бот.** В @BotFather отправьте `/newbot`, получите токен и вставьте его в админке → «Настройки». Нужен новый бот: бот Kezek уже занят. Затем нажмите «Подключить мой Telegram» — туда будут приходить заявки на оплату и новые ученики.
2. **Адрес сайта** — админка → «Настройки» → «Адрес сайта» (кнопки в сообщениях бота ведут туда).
3. **Оферта** — впишите свои данные в `terms.html` вместо текста в квадратных скобках.
4. **Самопроверка базы** — в Supabase → SQL Editor выполните `select * from private.self_test();`. Функция прогоняет 42 сценария (баллы ЕНТ, лимиты, оплата, права доступа) и откатывает все изменения.

## Как это устроено

```
GitHub Pages (статический сайт)         Supabase (проект talap-ent)
 index.html — лендинг                    Postgres + RLS: ученики, вопросы, ответы, тесты, оплаты
 app.html   — кабинет   ──RPC──▶         функции: выдача заданий без ответов, проверка, баллы ЕНТ
 admin.html — админка   ──REST──▶        pg_cron: напоминания (каждый час), окончание доступа (раз в день)
                                         pg_net → Telegram;  Edge Functions: account, tg
```

- `supabase/migrations/001_schema.sql` — вся база. Файл можно запускать повторно в SQL Editor.
- `supabase/functions/` — серверные функции `account` и `tg`.
- `supabase/tests/self_test.sql` — самопроверка.
- `js/` — код страниц без сборки, `vendor/` — supabase-js, `fonts/` — шрифты Golos Text и Unbounded (лицензия OFL).

### Защита ответов и подписки
- Ученик не видит таблицу вопросов. Задания приходят через функции **без правильных ответов**; ответ и объяснение возвращаются только после того, как ученик ответил.
- Баллы пробного ЕНТ считает база по правилам ЕНТ: 1 балл за задание с одним ответом; 2 балла за задание с несколькими ответами без ошибок, 1 балл при одной ошибке.
- Лимит бесплатных заданий и доступ к пробным тестам проверяются в базе, а не в браузере. Ученик не может сам продлить подписку: эти поля закрыты правами.

### Оплата
1. Ученик выбирает срок в «Профиль» → «Подписка», переводит деньги через Kaspi и нажимает «Я оплатил(а)», указав имя отправителя.
2. Вам приходит заявка в Telegram. Проверяете перевод в Kaspi → админка → «Оплаты» → «Подтвердить».
3. Доступ продлевается сам, ученику приходит сообщение. За 3 дня, за 1 день и в день окончания бот напоминает о продлении.

## Банк вопросов

Админка → «Вопросы»: правка, добавление, импорт и экспорт JSON. В таблице видно, какой процент учеников отвечает верно: если процент очень низкий, возможно, в вопросе ошибка. Ученики могут сообщить об ошибке кнопкой «Ошибка в вопросе?» — сообщения появляются в разделе «Ошибки».

Чтобы пробные ЕНТ не повторялись, держите в каждом предмете хотя бы втрое больше вопросов, чем в тесте: 60 по истории, 30 по каждой грамотности (6 текстов по 5 вопросов), 120 по математике и физике, из них 30 с несколькими ответами. Сейчас в банке 199 заданий — для первых учеников хватит, но расширять банк нужно в первую очередь.

Формат импорта (варианты перемешиваются автоматически, повторы пропускаются):

```json
[{
  "subject": "math",
  "topic": "Проценты",
  "questions": [
    { "body": "Найдите 15 % от 200.", "options": ["15", "30", "20", "45"], "answer": "B", "explanation": "200 · 0,15 = 30." },
    { "kind": "multi", "body": "Выберите чётные числа.", "options": ["2", "3", "4", "7", "10", "11"], "answer": "ACE" }
  ]
}]
```

Предметы: `history`, `mathlit`, `reading`, `math`, `physics`. Для заданий по тексту добавьте в блок `"passage": {"title": "…", "body": "…"}`.

**Правила содержания:** без примеров с процентами по кредитам и вкладам, алкоголем, азартными играми и лотереями; задачи на проценты — через скидки, наценки, рассрочку без переплаты.
